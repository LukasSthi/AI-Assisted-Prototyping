## Description
This project is a sustainability-focused AI platform designed to help users understand and reduce the environmental impact of AI usage. The platform provides an interactive dashboard with insights, prompt analysis, and optimization suggestions to improve efficiency. The goal is to create a smarter and greener AI experience for users.
